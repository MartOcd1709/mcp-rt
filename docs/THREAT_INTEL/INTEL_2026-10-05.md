## Top 3 recommended actions
1. **Family B — token passthrough / confused deputy probe.** Hottest uncovered class in 2026; needs a small OAuth test harness. Highest "eye-on-it".
2. **Rug-pull detector probe** (re-list tools over time, diff descriptions/schemas). Novel-ish, buildable agent-free, named concept.
3. **Investigate DuneSlide (CVE-2026-50548/9) sandbox-escape chain** — decide if it's a new probe class or a hunt-target signature.

🛡️ mcp-rt — Verify Attestation

Checks the Ed25519 signature entirely in your browser. Nothing is uploaded; no server is contacted. A valid result proves this exact attestation was signed by the holder of the stated key and has not been altered.

Generated by mcp-rt attest. The scan runs locally/in-VPC — tool metadata and secrets never leave the host; publishing an attestation is a separate, explicit choice. Learn more: github.com/MartOcd1709/mcp-rt
